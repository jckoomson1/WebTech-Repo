📘 ASHESI ATTENDANCE PORTAL SYSTEM
Activity 03 

1. PROJECT OVERVIEW
The Attendance PORTAL System is a simple web-based platform designed to help our school and  efficiently record, track, and manage attendance. The system includes user interfaces for login, attendance marking,record review and registration .  

This stage of the project focuses on establishing the project structure, HTML templates, and php for continued development of the website.

2. LEARNING OBJECTIVES 
- Apply HTML and CSS structure with php to create the foundation for the attendance system.  
- Organize the project using a consistent and maintainable folder system.   
- Prepare a good foundation for backend and database integration.

3. PROJECT REQUIREMENTS
- Maintain a single group folder for all project files.  
- Each team member has an individual subfolder for their personal work.  
- Follow established naming conventions and folder structure.  
- Include any shared HTML or setup files from Activity 02.  
- Ensure consistency across file references and link paths.  
- Prepare core pages such as:
  - Login Page  
  - User registration 
  - Dashboard  
  - Records Summary  


NAMING RULES:
- Use lowercase letters and underscores (no spaces).  
- HTML pages end with .html.  
- Personal folders should follow the format: Firstname_Role/.  
- Shared styles, scripts, and images remain in the /shared/ folder.

5. Save changes regularly and ensure all references work across the structure.
